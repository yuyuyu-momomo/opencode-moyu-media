# 聚合音乐简化版

在会话输入 `/music`，或点击侧栏顶部「音乐」。首次启动不播放；搜索后选择歌曲，再选「立即播放」或「加入播放队列」。同一首歌的不同平台版本分别显示，便于选择账号有权限播放的来源。

## 支持范围

| 功能 | 网易云 | QQ音乐 | 酷狗 |
| --- | --- | --- | --- |
| 搜索及加入统一队列 | 支持 | 支持 | 支持 |
| 公开歌单搜索 / 歌曲分页 | 支持 | 支持 | 支持 |
| 登录后查看自己的歌单 | 创建 / 收藏 | 创建 / 收藏 | 创建和收藏合并 |
| 个性推荐 / 私人电台 | — | 支持 | — |
| 普通平台授权地址播放 | 支持 | 支持 | 支持 |
| 扫码登录 | 网易云 App | 手机 QQ | 酷狗 App |
| 导入网页登录 Cookie | 支持 | 支持 | 支持 |
| 退出本地账号 | 支持 | 支持 | 支持 |

播放 / 暂停、切歌、前后 10 秒、音量及列表 / 单曲循环由统一播放器处理。`Alt+← / →` 在音乐页前后跳转 10 秒，`Alt+G` 输入秒数跳转，`Alt+D` 整理队列。队列最多 100 首，重启保留曲目、当前选择、音量及循环方式；点击播放后从开头开始。切回小说继续播放，切到视频暂停音乐。

## 多个 OpenCode 共用

使用相同资料库和密钥的窗口共用一个音乐引擎；搜索结果和对话框留在当前窗口，播放、队列、音量、循环和私人电台状态实时同步。并发入队由共享引擎处理，所有窗口都能暂停、切歌或退出电台；不会启动第二份音乐。

小说可与音乐同时使用。进入视频会暂停全局音乐；视频播放前等待音乐及其他窗口的视频停止，取得播放资格。播放视频期间其他窗口的音乐播放请求会提示先暂停或退出视频；视频暂停、结束或切走后释放资格，再手动恢复音乐。

窗口界面模式各自独立；默认尺寸、阅读进度等按键统一保存，更新一个设置不会覆盖其他窗口的新设置。账号写入统一排队，并用账号版本拒绝其他窗口退出 / 更新后才返回的旧扫码结果。IPC 使用资料库密钥认证加密，凭据不会以明文在窗口间传输。

隐藏面板或切会话不会误停其他窗口的音乐。承载共享运行层的窗口关闭时，媒体先停止，其他窗口自动重连并保持暂停，可再次点击播放。关闭最后一个窗口释放播放器。升级后重新打开所有实例，避免旧版独立播放器仍在运行。

## 登录

输入 `/moyu 登录qq音乐`，使用**手机 QQ**扫描默认浏览器显示的二维码，在手机确认即可。插件自动完成 QQ 授权、换取 QQ 音乐登录态和本地加密保存；不需要把 Cookie 复制给软件或 AI。也可输入 `/moyu 登录网易云`、`/moyu 登录酷狗`，使用相应手机 App 扫码。登录快捷命令适用于 OpenCode 2.x，在本地执行，不选择模型、不新建会话、不生成聊天消息。

三个平台都可从「账号」→ 平台 →「扫码登录」进入。QQ音乐菜单明确标注「手机 QQ」，该二维码使用 QQ 授权登录；网易云、酷狗使用各自 App。返回 OpenCode 后显示保存结果。等待最多 3 分钟，也可在音乐页或账号菜单取消；取消后丢弃这次扫码的迟到结果。本地二维码页面不使用外部二维码服务。

手机确认后，音乐面板依次显示获取授权、换取登录态及最终结果。失败原因会保留在面板中，成功后显示登录成功；打开「账号」时重新读取本地状态。QQ 授权按 Cookie 的域和路径处理同名记录，保留有效的 `graph.qq.com` Cookie 及 `pt_oauth_token`，避免其他域的清理记录覆盖授权信息。

需要手动导入时，点击「打开平台官网」，在网页正常登录。在浏览器开发者工具「网络」中刷新网页，选择该平台请求，复制请求标头的 `Cookie` 值，再回到「导入网页登录态」粘贴。QQ音乐需要包含 `uin` 或 `wxuin`，以及 `qqmusic_key` 或 `qm_keyst`；网易云需要 `MUSIC_U`，酷狗需要 `userid` 和 `token`。仅保存该平台播放需要的字段。

「已扫码保存」表示本次扫码成功并已保存；「已导入登录态」表示字段已保存，不代表服务端验证永远有效。过期后重新扫码或导入。退出只删除本软件保存的账号，不退出默认浏览器或手机 App。

账号、队列和偏好使用资料库的 AES-256-GCM 密钥分别加密，保存在书架 `.moyu/settings/music-*.enc`，密钥沿用书架旁的独立密钥文件。模型工具仅返回歌曲和歌单元数据，不提供获取或写入 Cookie 的接口；登录操作不创建模型消息。

## 歌单

音乐区点击「歌单」，选择「我的歌单」「我收藏的歌单」「搜索歌单」或「打开歌单链接 / ID」。平台按钮同时控制歌曲和歌单查询；选择「全部」查询个人歌单时只访问已登录的平台。酷狗目前不单独区分创建与收藏，统一放在「我的歌单」。网易云和酷狗个人账号查询尚未完成真实扫码账号验证。

歌单列表每个平台每页 10 个，歌曲每页 20 首，使用列表里的上一页 / 下一页继续查看。选择单首歌曲可播放或入队，「本页歌曲加入队列」按平台和歌曲 ID 去重；如果超过队列剩余容量则提示整理队列，本次不部分加入。关闭对话框后可从「继续查看上次歌单」返回，查询过程中可取消。

链接支持 QQ音乐、网易云、酷狗的完整官方歌单地址；也可输入 `qq:歌单ID`、`netease:歌单ID` 或 `kugou:歌单ID`，纯数字默认使用当前平台（全部时默认 QQ）。移动端短分享链接暂不展开，可改用歌单名称搜索。酷狗旧版数字链接通过官方 HTML 提取当前歌单 ID，不执行网页脚本。

`/moyu 查QQ音乐我的歌单` 使用 `moyu_music_playlists` 的 `mode=mine`；`/moyu 搜索通勤歌单` 使用 `mode=search`。工具每个平台每页最多 10 个歌单，默认模型任务先查 5 个；查看歌曲用 `moyu_music_playlist`，默认 20 首、最多 30 首。模型只读查询，播放和本地队列由音乐面板操作；不会修改平台歌单。

## QQ我喜欢与私人电台

「歌单」菜单里的「我喜欢 · QQ音乐」直接读取当前登录账号的爱心歌曲，也可在「我的歌单」首页找到它。它使用 QQ 的特殊目录，ID 为 `liked`，并非普通公开歌单链接。可按页查看和批量入队。`/moyu 我喜欢` 通过 `moyu_music_playlist(platform=qq,id=liked)` 查询。

音乐区点击「QQ电台」→「开始私人电台」，使用已登录 QQ 账号获取平台个性推荐并开始播放。每批 5 首，听完自动取下一批；下一首继续刷歌，上一首回听本次电台历史。电台期间保留原队列和原单曲 / 列表循环偏好，退出电台后回到原队列并保持暂停。也可以从普通队列选择歌曲，结束电台并播放所选曲目。

推荐和历史只保存在本次共享运行内，最多保留 100 首；电台不会覆盖已保存队列，重启恢复原队列并暂停。近期歌曲去重，连续返回重复或空结果时，每次补歌最多请求 3 批；平台拒绝则直接报告，未提供可播放地址时可点下一首。暂停、切到视频或关闭运行层会取消未完成的推荐请求，迟到响应不能恢复播放。

`/moyu 私人电台` 使用 `moyu_music_radio` 查询推荐，默认 5 首、最多 10 首，不控制声音；连续播放在本地音乐面板开始。该功能不修改平台的喜欢、收藏或不喜欢列表。

## 播放和实现

每个平台只解析其正常接口返回的播放地址。实际音频由 FFprobe 确认时长及音轨，FFplay 以 `-nodisp` 播放本地临时文件。媒体下载不携带 API 账号 Cookie，重定向逐次检查公开网络地址。单次最大 64 MiB，总请求时限 60 秒；加载中可以取消。试听片段在界面标明「试听」，来源拒绝或返回空地址时报告失败。

临时音频仅用于当前曲目，切歌、删除或退出后释放；缓存带进程编号，下次启动回收已经结束进程的残留目录。登录态与临时文件生命周期独立，删除队列不删除平台账号。多个平台的原始响应不直接入库，歌曲统一为平台、ID、标题、歌手、专辑、时长和平台链接。

`/moyu 音乐 搜索 …` 使用 `moyu_music_search`，支持 `all / netease / qq / kugou`，每个平台最多返回 10 首；默认模型任务每平台 5 首。平台歌单查询只读，编辑平台歌单、歌词和音乐离线资料库尚未接入。

实现参考了 [Listen1](https://github.com/listen1/listen1_chrome_extension) 的平台适配方式、[NeteaseCloudMusicApiEnhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced) 的扫码接口、[KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi) 的客户端协议，以及 [qq-music-api](https://github.com/Rain120/qq-music-api/blob/main/module/apis/user/checkQQLoginQr.js) 的 QQ 授权流程。本项目使用独立的轻量适配器，无需运行这些项目的 API 服务。相关协议实现的 MIT 版权声明保留在 `THIRD_PARTY_NOTICES.txt`；本地二维码使用 MIT 许可的 `qrcode`。
