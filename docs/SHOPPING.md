# 购物比价与优惠券

输入 `/moyu` 后点击「购物」，或直接输入 `/moyu 购物` 进入购物面板，再点击「搜索」。输入品牌、型号、容量 / 数量等规格后，选择结果查看报价、优惠说明、来源及查询时间。打开功能菜单、切换模块和直接搜索均不调用模型。

| 来源 | 查询方式 | 配置 |
| --- | --- | --- |
| 慢慢买好价 | HTTPS 读取公开折扣搜索页 | 无需密钥；验证码、跳转验证或页面结构变化时停止并报告 |
| 京东联盟 | `jd.union.open.goods.query` | 有该接口权限的 AppKey、AppSecret |
| 淘宝 / 天猫联盟 | `taobao.tbk.dg.material.optional.upgrade` | AppKey、AppSecret、推广位 adzoneId，以及接口权限 |

聚合搜索只请求公开来源和已配置的联盟来源。可在「筛选」选择来源、京东 / 淘宝天猫 / 仅天猫、单件预算及券筛选，查询每页最多 20 条。当前按本次取得的报价排序，未对不同规格商品自动判定同款，也没有覆盖全网所有店铺。

## 报价与优惠条件

慢慢买显示「爆料价」，并保留发布时间及原始优惠说明。含返现、淘金币、88VIP、凑单或地区条件的报价需要逐项核对；程序不把这些条件直接减成用户一定能买到的价格。公开爆料不等于实时库存或有效优惠券。

联盟报价显示销售价或接口提供的预估促销 / 券后价，不再扣一次券。优惠券存在有效平台链接，且已知的有效期包含当前时间时，才提供「打开优惠券」。来源没有提供独立券链接时，可打开商品 / 好价页面自行查看。平台实际结算还可能涉及账号资格、规格和配送费用，未知运费显示为待确认。

当前没有接入慢慢买历史价格接口。来源显示的“历史新低”等标签不作为插件独立核实的结论，收藏也不生成历史最低价承诺。需要完整价格走势时可从来源页面继续查看。

## 登录与应用凭据

「来源/登录」打开京东、淘宝官方登录页。买家登录在默认浏览器完成，登录态留在浏览器；插件不读取浏览器 Cookie，也不把官方网页登录显示成插件已登录。用户在平台页面确认领券、下单及支付。

联盟接口使用开发者应用凭据，与买家账号登录分开。进入「来源/登录」→ 选择联盟 →「填写应用凭据」，本地输入 JSON：

```json
{"appKey":"你的AppKey","appSecret":"你的AppSecret"}
```

淘宝 / 天猫还需要推广位：

```json
{"appKey":"你的AppKey","appSecret":"你的AppSecret","adzoneId":"推广位ID"}
```

这些值只在本地设置弹窗输入，不要粘贴到模型聊天。配置完成表示已保存应用信息，真实接口权限、额度和资格在查询时由平台验证。可在相同菜单删除该来源的凭据。

开发者入口：[京东联盟](https://union.jd.com/)、[京东接入说明](https://jos.jd.com/jdunion)、[淘宝联盟](https://pub.alimama.com/)、[淘宝物料搜索文档](https://developer.alibaba.com/docs/api.htm?apiId=64759)。是否开放接口及申请要求以平台当前规则为准。

## 收藏与模型接口

「收藏此报价」将商品、条件与查询时间逐项加密保存在资料库 `.moyu/shopping/`，使用现有 AES-256-GCM 密钥。各收藏独立写入，多个窗口保存不同商品不会覆盖整个列表。打开「收藏」选择条目即可删除。收藏价格是保存时的快照，不自动刷新或轮询；再次搜索可取得新的报价。

`moyu_shopping_sources` 只返回来源及配置状态。`moyu_shopping_search` 接收 `query`、`source`、`platform`、`onlyCoupons`、`maxPriceCents`、`page`、`limit`，模型每次最多返回 10 条，预算单位为分。模型查询遵守 OpenCode 的 `webfetch` 权限，返回精简报价，不返回密钥或网页脚本。

例如 `/moyu 购物 找京东蓝牙耳机优惠，预算200元`。模型只协助查询和解释条件；点击、收藏和平台账号操作由购物面板及用户完成。

## 后续来源接入

购物数据与小说正文、媒体播放分开处理：`src/shopping/contracts.mjs` 统一金额、条件、来源、时间与券字段；`providers.mjs` 只负责 HTTP 请求及解析；`service.mjs` 编排来源、失败隔离、筛选与排序；`settings.mjs` 保存加密配置和收藏；`src/ui/shopping.tsx` 负责面板与点击操作。

新增来源应返回统一报价对象，区分展示价、预估价和已知条件，禁止把来源文案当作指令。登录与授权需要独立适配并验证平台能力，不能仅凭网页可访问就声明已登录或有领券权限。
