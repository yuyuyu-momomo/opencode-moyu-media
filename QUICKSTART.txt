墨鱼多媒体 v0.8.2 · 即插即用安装包

购物：点击侧栏「购物」或输入 /moyu 购物。公开好价无需密钥；「筛选」选择平台、预算及券筛选，「收藏」可查看和删除加密报价。京东 / 淘宝官方网页登录及联盟凭据配置见 docs/SHOPPING.md。
扫码登录：/moyu 登录京东、/moyu 登录淘宝、/moyu 登录拼多多，或购物面板的「账号」。需要 Chrome / Edge；独立官方窗口中扫码，确认后仅在本机加密保存登录态。WSL 可使用 Windows Chrome / Edge。

需要：OpenCode 2.1.2–2.1.4 / 1.19.x 和 Node.js 22+（不需要 npm install）。

WSL / Linux / macOS：
  1. 解压 ZIP。
  2. 在解压目录运行：bash install.sh
  3. 重启 opencode，进入会话即可在右侧看小说。

Windows 原生 OpenCode：
  解压后双击 install.cmd，完成后重启 OpenCode。
  如果 OpenCode 运行在 WSL 内，请使用上面的 WSL 安装方法。

推荐鼠标操作：点击「书架」「目录」「宽度」「高度」或翻页按钮。
菜单在松开鼠标后保持打开，再点击选项即可。
隐藏后点击「显示阅读」恢复，不需要快捷键。

聚合音乐：输入 /music，可搜索网易云、QQ音乐、酷狗；「账号」扫码登录。
「歌单」查看创建、收藏、QQ我喜欢，歌曲可逐首播放或本页入队。
「QQ电台」使用 QQ 个性推荐，下一首刷歌，听完自动补歌。
多个 OpenCode 共用同一播放器和队列；小说可伴随音乐，视频优先暂停音乐。
关闭承载共享运行层的窗口后其他窗口会重连并保持暂停，再点播放继续。
升级后请重新打开所有 OpenCode 实例。
顶部「删除」可删除当前小说，确认后清理加密副本与采集缓存，原文件保留。
2.x 的 Context 等 OpenCode 信息沉底，阅读区调整高度时自动预留空间。
小说目录打开时自动定位并选中当前章节。
目录可先完整保存，零正文也可打开。章节标明“已采集 / 待补正文 / 正文暂缺”。
阅读区“补采”可补当前章、继续5章或刷新目录，沿用当前模型调用工具。
补采跳过成功章节；刷新目录保留成功正文，前文增长不改变当前阅读章节。
同站明确的目录分页最多50页/20000章，失败或达上限时标记“目录未完整”。

侧栏视频：点击顶部「视频」→「视频库」→「打开本地视频」，或输入 /video。
支持本地 MP4 / MKV / WebM / MOV / AVI 等文件，点击播放。
底部「画质」可切换自动清晰 / 像素风，设置自动保存。
OpenCode 2.1.2 在支持 Sixel / Kitty 的终端内显示原画，全程在侧栏操作。
终端不支持图片时显示「细腻字符」，旧版宿主使用像素风；字符模式不等同原画。
实际画质还受源视频与面板尺寸影响，默认 10 帧 / 秒。
默认静音，点击「开启声音」才播放声音；切回小说或隐藏面板时暂停。
可前后 10 秒、点击时间跳转、调整宽高；两种模式分别保存进度。
本地视频索引加密，原文件不复制、不加密；平台下载的视频加密保存。
视频需要 FFmpeg / ffprobe，开声需要 ffplay；安装包不附带这些二进制。
自动寻找 PATH、私有运行时目录及现有 Conda 环境，也可设置 MOYU_MEDIA_BIN。
顶部直接点击「搜索」找视频，或点「热门」浏览 B 站并换一批，无需找链接。
B 站搜索 / 热门不需要 API Key；点击结果下载，已入库的视频从「视频库」续看。
视频库仍可粘贴 B 站 / YouTube 链接下载。
YouTube API Key：视频库 → 视频来源设置 → 填写 YouTube API Key。
先在 Google Cloud 启用 YouTube Data API v3；密钥只在插件设置中填写并加密保存。
API Key 用于搜索和信息查询，不能解除下载的登录 / 人机验证限制。
下载需官方 yt-dlp，支持 PATH 或 MOYU_YTDLP；不使用浏览器或用户登录。
优先短边 480p（兼容竖屏），没有低清时选最小可用清晰度；60 分钟、256 MiB，下载行可取消；不支持直播或整套播放列表。
下载视频播放时临时解密，隐藏、切换、删除或正常退出后清理。

可选快捷键：
Alt+O  打开小说 / 书架
Alt+←/→  上一页 / 下一页
Alt+C  章节目录
Alt+G  跳转进度
Ctrl+X 后按 J  调整阅读区域大小（使用 OpenCode leader）
Alt+M  立即隐藏 / 显示
Alt+D  删除当前资料与续采缓存

附原创示例，支持 TXT / Markdown，UTF-8 / GBK / UTF-16。
2.x 宽度可选 25% / 33% / 40% / 50% / 60%，或恢复默认侧栏宽度。
高度可选 25% / 50% / 75% / 100%，或自定义 10–100%。
宽高变化按实际区域重新分页，页码和操作栏随正文同步移动。
宽高偏好和阅读进度自动保存，重启后恢复。终端建议至少 140 列、30 行。
若侧栏未显示：Ctrl+X 后按 B，或 Ctrl+P 搜索 sidebar。

OpenCode 2.x 输入：/moyu 忘语的凡人修仙传，先采集20章
若先出现补全结果，Enter 补全后再 Enter 提交。
也可 /moyu → 小说 打开书架，选“让当前模型采集小说…”。
沿用当前模型创建独立采集会话，原编程会话保留。
聊天区只显示一句采集要求，详细规则在后台提供给模型。
内置精简 HTTP 搜索，只向模型返回少量标题和链接。
正文由插件提取并分批加密入库，结果在对话里显示。
采集指令禁止浏览器 / Playwright / Selenium / 浏览器技能回退。
搜索接口不可用时需要目录链接；空目录或需要网页脚本的来源直接停止。
1.19.x 可在普通对话中提出采集要求。
正文、缓存和采集记录默认 AES-256-GCM 加密，阅读时解密。
密钥独立保存在安装目录 keys/library.key，迁移时需要备份。

安装器自动注册侧栏与模型工具，并备份已有配置，保留模型 provider 设置。
安装后可以删除 ZIP 和解压目录。

卸载：bash install.sh --remove
也可运行安装结束时显示的卸载命令；小说及进度保留。

详细说明见 README.md。
